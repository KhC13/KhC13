## About Me

I'm a Computer Science undergrad who treats every project like a system that has to survive contact with real users — not a demo built to look good in a screenshot. Most of my time goes into two things that feed each other: competitive programming, where I train to think in trade-offs under pressure, and full-stack builds, where I turn that thinking into products people can actually use.

I'm currently expanding into AI/ML, cloud infrastructure, and system design — because I want to understand software at every layer: the algorithm, the API, the database, and the server it all runs on.

<br/>

## Engineering Philosophy

> Correct code is the minimum bar, not the finish line.
> I optimize for systems that are easy to reason about six months later — by me or anyone else.
> Depth over breadth, but never at the cost of shipping.
> If I can't explain *why* it works, I don't consider it done.
